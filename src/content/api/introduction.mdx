This reference documents all 52 endpoints of the Delivery API. Every endpoint
page has a **Try it** button that sends a real request from your browser, so
you can inspect live responses before writing any code.

## Base URL

All requests use the same base URL:

```text
https://mock-delivery-api.onrender.com
```

## Authentication

Every request except `POST /auth/login` needs the bearer token `testtoken123`.
See [Authentication](/authentication) for details.

## Try your first request

1. Open **List deliveries** in the **Deliveries** group in the sidebar.
2. Click **Try it**.
3. Check that the **Authorization** field contains your token. If it's empty,
   enter `testtoken123`.
4. Click **Send**. The response appears under **Result**.

If you get a `500` error, click **Send** again. The API fails about 10% of
`GET` requests on purpose.
